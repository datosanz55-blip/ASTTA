### Подключение Telegram через отдельный VPS

Сайт, webhook `https://astta.ru/api/tg/webhook`, очередь и база заявок остаются на сервере ASTTA. Зарубежный VPS проксирует исходящие запросы к Bot API. Порт базы и админку на VPS открывать не нужно.

После обновления ASTTA, перед переключением на VPS, запустите на сервере ASTTA:

```sh
cd /opt/astta
docker compose -f infra/docker-compose.yml --env-file infra/.env exec backend python manage.py telegram_check
```

Если Bot API отвечает, диагностика также покажет URL вебхука, очередь входящих обновлений и последнюю ошибку Telegram. Ошибку вебхука нужно устранять на стороне ASTTA, смена исходящего маршрута сама её не устранит.

1. Создайте DNS-запись для отдельного имени, например `tg-relay.astta.ru`, ведущую на зарубежный VPS. Для этой конфигурации нужны свободные TCP-порты 80 и 443. Если VPS уже обслуживает другие сайты через Caddy, добавьте блок сайта из Caddyfile в существующий Caddy, вместо запуска второго экземпляра на тех же портах.
2. Скопируйте `Caddyfile` и `compose.yaml` в один каталог на VPS. Создайте в нём закрытый `.env` с `ASTTA_RELAY_DOMAIN=tg-relay.astta.ru` и `ASTTA_RELAY_KEY=<случайный ключ>`. Ключ можно сгенерировать командой `openssl rand -hex 32`. Права файла — 600.
3. Выполните `docker compose up -d` на VPS. Дождитесь выпуска TLS-сертификата. Неподписанный запрос к корню адреса посредника должен вернуть 404.
4. В `infra/.env` на сервере ASTTA укажите `TELEGRAM_API_URL=https://tg-relay.astta.ru` и `TELEGRAM_API_RELAY_KEY` с тем же случайным ключом. Пересоздайте `backend`, `worker` и `beat`. Существующий токен бота и секрет вебхука оставьте на ASTTA.
5. Повторите `telegram_check` на ASTTA и проверьте сообщение `/start` в боте. Если URL вебхука уже правильный, регистрировать его заново не требуется. Чтобы обновить команды бота или исправить неверный URL, запустите `python manage.py telegram_setup` в контейнере `backend`.

Для отката уберите обе переменные посредника и пересоздайте контейнеры ASTTA. Не включайте журналы доступа на посреднике без удаления токена из URL.
