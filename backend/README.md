# ASTTA backend

Сервер площадки: каталог, цена под ключ, заказы, админка для команды и кабинет поставщика на китайском (`/seller/`).

Стек: Python 3.12, Django 5.2, Django Ninja (API), PostgreSQL 16, Celery + Redis (фоновые задачи), Unfold (оформление админки).

## Что уже есть

- **Каталог.** Поставщики, категории, товары с названием и описанием на русском и китайском, оптовые ступени, фото, модерация (черновик → на модерации → опубликован или отклонён).
- **Цена под ключ.** Формулы те же, что в прототипе: товар по курсу, доставка по весу, сервисный сбор 5% в рознице и 3% в опте, итог округляется до 10 ₽. В админке «Комиссии» можно задать свой сбор для категории или поставщика: правило поставщика важнее правила категории, пустое поле значит общий сбор. Ставка, по которой посчитан заказ, сохраняется в каждой строке заказа. Крупногабарит едет только сборным грузом. Тарифы, сборы и надбавка к курсу меняются в админке без выкладки кода.
- **Курс юаня.** Фоновая задача раз в 3 часа берёт курс с сайта ЦБ РФ. Вручную: `python manage.py update_rate`.
- **Заказы.** Покупатель платит сразу при заказе, цена фиксируется в момент заказа. Размер и цвет выбираются только из списков товара, одинаковые строки корзины складываются. Неоплаченный за сутки заказ отменяется сам (фоновая задача). Пока нет эквайринга, оплату отмечают в админке действием «Оплата получена». Дальше агент меняет статус и добавляет фото со склада и фактический вес, покупатель видит историю по ссылке с токеном.
- **Загрузка каталогов командой.** Поставщики из Китая в систему не заходят: присылают каталоги, а на сайт их выкладывает команда ASTTA в кабинете `/seller/` (переключатель поставщика вверху) или в админке. Excel по русскому шаблону плюс ZIP с фото: имя файла начинается с артикула (`A-101.jpg`, `A-101_2.jpg`) или фото лежит в папке с артикулом. Новые фото товара заменяют старые, можно загрузить только архив к уже заведённым товарам. Если в файле или архиве есть ошибка, не загружается ничего, а список ошибок показывается по строкам. Товары от команды публикуются сразу. Фото хранятся уменьшенными до 1600 px в WebP: каталог быстро открывается с телефона.
- **Посты в ленту.** Команда публикует от имени поставщика пост с текстом и до 10 фото, с товаром или без. Лента для витрины: `GET /api/feed`.
- **Кабинет для поставщика** (на китайском) остаётся на будущее: поставщик видит только свои товары и заказы, его правки проходят модерацию, контакты покупателей он не видит.
- **Выкуп у поставщиков и выплаты.** После оплаты заказ сразу делится на задания по поставщикам: заказать → заказано у поставщика → отправлено на склад (трек) → склад принял. Страница «Заказать у поставщиков» в админке (и вкладка «Заказы» в кабинете) складывает одинаковые товары из всех оплаченных заказов и готовит сообщение поставщику в WeChat на китайском: артикулы, цвета, размеры, количество, ссылки и номера заказов для коробки. Нет товара — часть заказа отменяется, сумма за неё попадает в «к возврату». Статус для покупателя двигается сам: все части заказаны → «выкуплен», все на складе → «на складе в Китае». Выплата поставщику собирается из принятых складом частей, сумма — цена поставщика в юанях без сервисного сбора: сбор платит покупатель сверху.
- **Заказ по ссылке.** Покупатель вставляет ссылку или целиком сообщение «поделиться» из приложения. Узнаём площадку (1688, Taobao, Tmall, Pinduoduo, Poizon) и номер товара. Если товар уже загружен в каталог с той же ссылкой у поставщика, показываем его сразу. Иначе считаем предварительную цену под ключ по цене в юанях: вес — средний для категории в нашем каталоге, сбор — по правилам комиссии, плюс надбавка площадки и доставка по Китаю (задаются в админке «Площадки»). Заявка с фото уходит агентам в админку «Заявки по ссылке».
- **Модерация.** Модератор открывает кабинет любого поставщика (в админке у поставщика действие «Открыть кабинет поставщика» или переключатель вверху `/seller/`) и работает в нём от имени поставщика. Посты можно вести и в админке: текст для покупателей и фото.
- **Роли.** Группы прав создаёт `python manage.py setup_roles`:
  - **Модераторы:** любые товары, поставщики, заказы, курс и тарифы; пользователей только смотрят, чтобы никто не мог выдать себе лишние права;
  - **Поставщики:** кабинет `/seller/` со своими товарами и заказами, без права публиковать;
  - **Агенты:** заказы, статусы, фото со склада, приёмка частей заказа от поставщиков.
- **Основатели** работают как суперпользователи (`python manage.py createsuperuser`): им доступно всё, включая создание аккаунтов поставщиков и модераторов.

## API

Документация с примерами открывается на `/api/docs`.

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/api/categories` | категории |
| GET | `/api/products?category=&q=&sale=&new=&sort=&page=` | каталог с ценой под ключ |
| GET | `/api/products/{slug}` | карточка: оптовые ступени, фото, фактический срок поставщика |
| GET | `/api/feed?supplier=&page=` | лента поставщиков: посты с фото и товаром |
| POST | `/api/link/lookup` | узнать площадку по ссылке и найти товар в каталоге |
| POST | `/api/link/estimate` | предварительная цена под ключ по цене на площадке |
| POST | `/api/link/requests` | заявка агенту: ссылка, фото, цена, размер |
| GET | `/api/quote?product=&qty=&mode=retail\|wholesale&shipping=` | цена с расшифровкой |
| GET | `/api/rate`, `/api/shipping` | курс и способы доставки |
| POST | `/api/orders` | оформить заказ: товары с размером и цветом, оплата сразу |
| GET | `/api/orders/{token}` | заказ и трекинг |

Кабинет поставщика работает через `/api/seller/*`: вход по логину и паролю (сессия и CSRF-токен, не больше 10 попыток в минуту), товары, фото, импорт из Excel и ZIP с фото, посты, выплаты, настройки магазина и контент-завода. Модератор передаёт код поставщика в заголовке `X-Act-As`. Все адреса с описанием — в `/api/docs`, раздел «Кабинет поставщика».

## Запуск на своём компьютере

```bash
cd backend
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
export DJANGO_DEBUG=1
python manage.py migrate
python manage.py seed_demo --orders --users   # 18 товаров, тарифы, курс 11,40 ₽, заказы и входы поставщикам
python manage.py createsuperuser
python manage.py runserver
```

Админка: http://localhost:8000/admin/, кабинет поставщика: http://localhost:8000/seller/, API: http://localhost:8000/api/docs.

`--users` создаёт вход `{код}_supplier` для каждого поставщика и печатает пароли один раз. Суперпользователь открывает `/seller/` как модератор и выбирает поставщика вверху.

Без переменной `POSTGRES_DB` проект работает на SQLite. Для разработки этого хватает, но в SQLite поиск по русскому тексту чувствителен к регистру, поэтому тесты и сервер работают на PostgreSQL.

## Тесты и проверки

```bash
POSTGRES_DB=astta POSTGRES_USER=astta POSTGRES_PASSWORD=... POSTGRES_HOST=localhost pytest
ruff check .
```

Те же проверки запускает GitHub Actions на каждый PR (`.github/workflows/ci.yml`).

## Сервер

`infra/docker-compose.yml` поднимает базу, Redis, API с админкой и кабинетом поставщика и фоновые задачи на одном сервере. Образ собирается из корня репозитория (`docker build -f backend/Dockerfile .`): в него попадают сервер и файлы кабинета, остальное отсекает `.dockerignore`. Сервер должен стоять в России: персональные данные покупателей по 152-ФЗ хранятся в России.

```bash
cp infra/.env.example infra/.env   # заполнить секреты
docker compose -f infra/docker-compose.yml --env-file infra/.env up -d --build
docker compose -f infra/docker-compose.yml exec backend python manage.py createsuperuser
```

HTTPS и домен настраиваются на обратном прокси (Caddy или nginx) перед портом 8000: он же включает редирект на HTTPS и HSTS. Разрешите на прокси загрузку файлов до 1 ГБ и ожидание ответа до 3 минут: архив на 300 фото обрабатывается около минуты.

## Переводы

Строки интерфейса на китайском лежат в `locale/zh_Hans/LC_MESSAGES/django.po`. После изменения текстов:

```bash
python manage.py makemessages -l zh_Hans --ignore=staticfiles
# дописать переводы в django.po
python manage.py compilemessages
```

## Чего пока нет

- Сайт для покупателей на реальном API (следующий шаг, Next.js).
- Автоперевод названий на русский в кабинете: сейчас переводит модератор.
- Распознавание цены на фото и поиск по фото в заказе по ссылке: нужна модель ИИ.
- Надбавки площадок (Poizon и др.) и доставка по Китаю: впишите в админке по тарифам TT, сейчас там нули.
- Вход по Telegram и СМС, оплата (ЮKassa), уведомления в Telegram, хранилище фото в S3, ASTTA AI.
- Часть служебных надписей Unfold («Filters», поиск) остаётся на английском: у темы нет китайского перевода.
